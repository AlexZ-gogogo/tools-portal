# 更新日志

本文档根据 Git 提交历史整理，用于记录项目主要功能更新和修复内容。

## 2026-09-30

1. 新增 Azure OpenAI 模型 `gpt-6.1-sol`。

## 2026-09-23

1. 新增 Azure OpenAI 模型 `gpt-6-sol` 和 `gpt-6-luna`。

## 2026-09-11

1. 新增 Azure OpenAI 图像模型 `gpt-image-2.5-flare` 和 `gpt-image-2.5-sunburst`。

## 2026-09-05

1. 新增 Azure OpenAI 模型 `gpt-6-astra`。

## 2026-09-02

1. 新增 Foundry 专属 Kimi K3 模型部署能力。
2. 新增订阅准备页面。
   - 支持批量查询订阅的 `Microsoft.CognitiveServices` 资源提供程序注册状态。

## 2026-09-01

1. Foundry 批量部署流程新增默认 Project 创建能力。
2. 新增 Foundry 专属 Grok 模型 `grok-4-1-fast-non-reasoning`、`grok-4-1-fast-reasoning` 和 `grok-4.6`。

## 2026-08-31

1. 新增现有资源部署能力。
2. 优化单订阅和多订阅部署交互。
3. 从部署模型清单中移除已退役的 `gpt-5.3-chat` 和 `gpt-5.1-chat`。
4. 单订阅、多订阅和现有资源部署页面接入暂停部署功能。

## 2026-08-23

1. 新增多订阅批量部署能力。
   - 单次多订阅部署限制最多选择 20 个订阅，避免一次性任务过大。
2. 优化登录体验。
   - Microsoft 登录改为显示账号选择页，便于从已有账号中选择或使用其他账号登录。

## 2026-08-06

1. 修复批量部署日志统计中“进行中”数量显示错误的问题。
2. 修复批量部署过程中 Azure 登录 token 过期导致后续部署失败的问题。
   - 后端新增 MSAL 静默续期逻辑，access token 快过期或过期时自动获取新 token。
   - 部署任务改为通过会话按需获取 token，避免长时间任务一直使用启动时的旧 token。
   - 增加应用侧登录会话空闲超时和 24 小时绝对超时兜底。

## 2026-08-03

1. 批量部署前自动检查并注册资源提供程序。
   - 部署 Azure OpenAI / Foundry 前检查 `Microsoft.CognitiveServices` 注册状态。
   - 未注册时自动发起注册，并按超时控制轮询等待注册完成。
   - 注册失败、权限不足或等待超时时输出明确日志并终止本次部署。

## 2026-07-31

1. 查询订阅配额等级页面新增升级策略展示。
   - 后端透传 Azure 返回的 `tierUpgradeEligibilityInfo`。
   - 前端在表格中显示计划升级时间和目标配额等级。
   - 无计划升级时显示“暂无计划升级”。
2. 查询已部署模型页面补充内容筛选器数据展示能力。
   - 后端库存接口返回部署的 `raiPolicyName`。
   - 前端现有内容筛选器列可显示对应筛选器名称。
3. 优化订阅下拉框显示顺序。
   - 新增公共订阅选择组件，批量部署页面和查询已部署模型页面复用同一套下拉框展示逻辑。
   - 订阅列表按订阅名称自然排序，同名时按订阅 ID 排序。
4. 修复查询已部署模型页面资源数量不完整的问题。
   - 后端查询 Cognitive Services 账号列表时支持 Azure ARM `nextLink` 分页。
   - 避免订阅下资源较多时只展示第一页资源。
5. 优化查询已部署模型页面统计卡片配色。
   - 将“资源总数”卡片调整为独立底色，避免与“Azure OpenAI”卡片颜色重复。
